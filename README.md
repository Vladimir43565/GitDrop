GitDrop

GitDrop is a lightweight desktop application that allows users to quickly download and extract GitHub repositories into a local folder with one click.

Instead of manually downloading ZIP files or using Git commands, users can paste a GitHub repository URL, choose a destination folder, and GitDrop automatically handles the rest.

Features
Paste any GitHub repository URL
Automatic support for main and master branches
Choose destination folder
One-click download and extraction
Opens project folder automatically after installation
Background processing to keep the UI responsive
Simple and beginner-friendly interface
How It Works
Enter a GitHub repository URL
Select a destination folder
Click Install Project
GitDrop downloads and extracts the repository
The project folder opens automatically
Requirements
Python 3.8 or higher (for source version)
Internet connection

If using the executable version, no installation is required.

Status

GitDrop is currently in beta.
It is stable for basic use, but may still receive improvements and bug fixes.

Goal
